# 吾侠 (Wuxia Crafting Tool)

**吾侠** 是一款专为武侠题材跑团（TRPG）设计的辅助工具。本项目的核心理念是将 **D&D 4E (龙与地下城第四版)** 严谨的战术战斗规则与富有东方韵味的 **武侠设定** 相结合，为 DM 和玩家提供便捷的资源制作与管理体验。

## ✨ 设计理念

本项目深受 D&D 4E "威能 (Powers)" 系统的启发。在 4E 中，每个职业都拥有 At-Will (随意)、Encounter (遭遇) 和 Daily (每日) 威能，这种设计非常适合表现武侠小说中不同层次的武功招式：

*   **外家功夫 (At-Will)**: 基础招式，如拳脚刀剑的常规套路，可随时施展，生生不息。
*   **催动内息 (Encounter)**: 需调动真气爆发的强力招式，战斗中由于内息回转限制，通常使用频率有限（对应遭遇威能）。
*   **凝神绝技 (Daily)**: 消耗大量精气神的必杀技，威力巨大但消耗甚重，往往需要修整方可再用（对应每日威能）。

通过这种对应，我们将冷冰冰的规则数据转化为生动的江湖武学，既保留了 4E 优秀的战术平衡性，又赋予了其浓厚的武侠风味。

## 🛠️ 功能列表

本工具包含九个资源制作模块，用于编写、预览和导出独立的第三方资源：

1.  **⚔️ 武学招式库 (Moves)**
    *   类似于 4E 的威能卡。
    *   支持自定义招式类型（外家/内息/绝技）、动作类型、射程范围、攻防检定等。
    *   内置“关键词”系统（外功、内功、音波、纯阳等），方便规则结算。

2.  **🧬 根骨天赋库 (Roots)**
    *   对应种族 (Race) 设定。
    *   定义角色的基础属性加成、体征以及独有的天赋绝学。

3.  **🔮 先天命格库 (Destinies)**
    *   与根骨、出身共同拆分原版种族信息；此模块承载先天特殊能力。

4.  **🏯 江湖出身库 (Origins)**
    *   与根骨、先天命格共同承载拆分的种族信息，也可记录背景。
    *   提供语言、技能加成和出身特性。

5.  **🧘 武道造诣库 (Feats)**
    *   对应专长 (Feats)。
    *   提供各类被动加成，丰富角色的构建深度。

6.  **🗡️ 神兵宝甲库 (Items)**
    *   对应魔法物品 (Magic Items)。
    *   记录武器装备的等级、价值、部位、暴击效果及附带神通。

7. **🏯 武林门派库 (Schools)**
    *   对应职业概要，记录生命、回复力、熟练项、受训技能和门派特技。

8. **📜 修行传承库 (Traditions)**
    *   对应典范之道，卡片依次展示名称、起始等级、引言、前提、资源说明、分级特性、附属威能与来源。
    *   默认特性节点为 11、11、16 级；默认威能节点为 11、12、20 级，使用频率分别为遭遇、每日、每日。

9. **☯️ 成道之途库 (Paths)**
    *   对应传奇命运，沿用传承卡片结构，并增加可选的终局标题和终局／不朽说明。
    *   默认特性节点为 21、24、30 级，附属威能默认在 26 级获得、每日使用。

两类新增资源的等级节点与数量均可修改，不限定世界观。附属威能支持使用频率、动作、关键词、范围、触发、目标、攻击、命中、失手、效果、维持和特殊规则，内嵌于资源 JSON 中，可独立备份与分享。卡片保留文本换行，未填写的特性和威能不会显示；整张资源卡可使用现有按钮下载或复制 PNG。

## 🚀 特色功能

*   **可视化卡片生成**: 所有资源均可实时预览为精美的“武侠风”卡片样式。
*   **本地化存储**: 所有数据保存在浏览器本地，无需联网即可使用。
*   **全局搜索**: 支持跨库关键词搜索，快速查找所需条目。
*   **图片导出**: 支持将制作好的卡片一键导出为 PNG 图片，方便分享或打印。
*   **数据导入/导出**: 支持带版本的全库、单条及选中条目 JSON 导出；导入先校验并预览，再选择跳过、覆盖或复制重复条目。兼容旧版 JSON 与本地存储。
*   **创作管理**: 支持条目复制、库内全文搜索、特性与附属威能排序；空库由作者主动新建。
*   **规则保留**: 普通招式与附属威能共用编辑和卡片组件，支持附加规则段、独立获得等级、原版来源及对照原文。
*   **保存反馈**: 存储损坏时保留原始内容并暂停覆盖；空间不足时保留内存草稿，提示导出备份或重试。
*   **传承图片导出**: 支持完整卡、概要卡与单张附属威能；预览缩放不改变导出尺寸。

## 开发与资源格式

本工具负责资源创作，不执行完整角色构建或强制世界观规则。4E 原版数据的只读模板接入是后续工作，当前不会自动载入整套原版资料。

执行 `npm ci` 安装依赖，使用 `npm run dev` 启动开发环境。修改后运行 `npm run lint`、`npm run typecheck`、`npm test` 和 `npm run build`。

格式与兼容规则见 [资源模型](docs/resource-model.md)，编辑与导出规则见 [卡片格式](docs/card-format.md)。项目协作约定见 [AGENTS.md](AGENTS.md)，本地转换技能位于 `.agents/skills/4e-resource-adapter/SKILL.md`。

代码分层与维护边界见 [架构说明](docs/architecture.md)。

工具栏“术语库”可管理分类词、改名与隐藏、导出词库，并开关新词自动收录。候选保留现有武侠词并加入 187 个本地 4E 参考术语；卡片保留自由输入，词库改名不批量改写已有卡片。全库备份包含术语；独立词库 JSON 从同一“导入 JSON”入口导入。详见 [分类术语库](docs/terminology.md)。
