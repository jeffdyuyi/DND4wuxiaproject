# 标题色带

只改变卡片顶部名称和等级所在的 `.card-header`，不改变正文、意境、规则行、行动标记和字体。标题文字按亮度选择白色或墨色，墨色文字取消黑色投影以保持可读。

## 基准来源

## 数据和使用

资源的可选 `headerColor` 字段保存六位 `#RRGGBB`，导入时校验并统一为大写；缺少字段的旧资源按类型默认色显示，无需改写旧存档。恢复默认色删除覆盖值，招式随后继续跟随使用频率变化。复制、另存、JSON、可编辑 PNG 和 ZIP 复用现有资源序列化，因此保留颜色。单独和内嵌威能均通过 PowerEditor 和 PowerCard 使用同一套处理；父卡颜色不会覆盖附属威能。

编辑器的“标题色带”面板支持原生取色和十六进制输入。无效输入不会写入卡片。颜色改变仍是草稿，按现有保存按钮或快捷键提交。正文用的原有全局颜色变量不改动。

## 配色库与批量应用

“标题色带与配色库”面板提供只读内置色，以及可命名保存的“我的配色”。同一色值再次保存更新名称，不重复创建；点选配色修改当前卡片草稿，删除配色仅删除快捷选项，不改动已保存的卡片。保存配色库和保存当前卡片是独立操作。

配色库以 `{ schemaVersion: 1, colors: [{ id, name, color }] }` 存入独立本地键 `wuxia_title_colors_v1`。旧版本没有该键时使用空自定义库与内置色。读取损坏的库时保留原文、停止覆盖并提供恢复原文导出；写入失败不显示保存成功。它属于当前浏览器的个人设置，不包含在全库卡片备份中；卡片本身的色值仍随 JSON、PNG、ZIP 分享，接受方不依赖配色库。

资源列表的“批量选择、配色与打包”面板可给选中的条目应用内置或自定义颜色，也可恢复各条目类型默认色。筛选后的隐藏选中项仍计入明确显示的选中数量。默认仅改变父卡标题；传承与成道资源可勾选同时应用到附属威能。批量应用直接提交到本地资源库，存储失败沿用全局错误及重试处理。存在草稿、数据恢复阻塞或正在打包时禁止执行，避免悄悄保存或覆盖编辑稿。
