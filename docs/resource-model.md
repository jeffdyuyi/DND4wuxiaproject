# 资源数据模型

## 身份与类目

`src/types.ts` 的 `ResourceMap` 将九个类目映射到各自资源类型，`DB` 按此映射保存数组。`id` 使用 UUID；条目名称允许暂时为空。已存在的旧 ID 保留，重复导入通过跳过、覆盖或分配新 ID 的副本处理。

根骨／出身／先天命格是种族信息的拆分。修行传承与成道之途是独立资源组合，特性和威能带稳定 ID，附属威能随资源导出。复制资源时递归更新所有内嵌 ID。

## 威能与复杂规则

`MoveItem.type` 的 basic/special/ultimate 分别表示随意／遭遇／每日，不限制外家、内家等风味。动作使用 `ActionMap` 的键，防御使用 AC/Reflex/Fortitude/Will；迁移中文旧值。旧 `react` 保留为“变招（旧版）”，不推测作者指即时打断还是即时反应。

`level` 是威能等级；`acquiredLevel` 是组合资源中的获得等级，两者独立。`rules` 是可排列的标题／全文段落，承载次攻击、强化、后续效果、次威能等复杂结构。`source` 是出处，`sourceText` 保留完整参考原文，不印在卡片上。未知扩展字段保留。

## 版本与恢复

卡片编辑先进入 App 的独立草稿，明确选择覆盖、复制或改名另存后提交到 useLibrary。切换页面和关闭浏览器有未保存提示；全库备份包含当前编辑稿。单卡 PNG、JSON 与 ZIP 的往返及保存行为见 [卡片分享](card-sharing.md)。

备份格式：`{ schemaVersion: 1, exportedAt, data: { moves: [...], ... } }`。支持全库、单类目与单条资源备份，仍可导入旧版直接按类目排列的 JSON。缺少类目视为空库；支持的资源字段类型错误或未来版本导致整次导入失败，不部分写入。

作者主存档使用 IndexedDB `wuxia_author_v1`，资源与术语存为同一版本化记录，整库原子写入。首次启动优先读取已迁移的 IndexedDB 记录；没有记录时读取 `wuxia_resources_v1` 或 Config 旧类目键，校验后迁移。旧 localStorage 原文不删除、不改写，成功迁移后的后续修改不再同步回旧键。新存档损坏时不静默退回过时的旧副本。浏览器不支持 IndexedDB 时保留旧存储模式并提示容量限制。

资源可选 `headerColor` 为六位 `#RRGGBB`，只覆盖标题色带；缺省使用类型默认色。导入拒绝非法颜色，保留旧资源兼容性。附属威能独立保存自己的覆盖色，详见 [标题色带](card-colors.md)。

加载异常保留原始字符串与错误，暂停自动保存。作者先下载恢复原文，再明确选择用当前数据继续。写入失败保留内存中的编辑稿，提示未保存、支持重试和 JSON 备份，并在离开页面时提醒。恢复文件属于原始故障快照，不是可直接导入的资源备份。

4E 原版资料使用独立的 IndexedDB 缓存层，资料包支持远程获取或本地导入；仅选中并复制的草稿进入作者存档。缓存的原子更新、容量显示、来源快照与转换边界见 [只读模板库](templates.md)。

外层增加可选 `terminology` 字段，与资源同键保存。旧版本 1 存档缺少此字段时加载默认术语；词库故障保留原始存档并暂停覆盖。动作、防御、频率旧名称快照保留在资源扩展字段；显示按稳定标识读取当前置换，详细行为见 [分类术语库](terminology.md)。

全库备份可选 `colors` 保存自定义配色，旧版本 1 文件缺少此字段仍兼容。此字段由完整校验入口读取，不进入卡片日常存档；恢复与分享边界见卡片分享文档。

## 作者存档与恢复草稿

加载期间暂停创作入口，避免初始化结果覆盖先前编辑。IndexedDB 保存检查当前修订号：两个标签页同时写入时，旧版本的写入失败并提示先导出再刷新。普通资源更新保留失败时的内存数据；卡片覆盖或另存使用 commit，持久化成功后才替换当前卡和完成导航，失败保留原卡与编辑稿。

恢复草稿独立存放于 drafts，每个页面会话使用独立 ID。编辑写入串行执行并合并尚未开始的旧请求，保存结果有明确状态。成功提交卡片时，同一事务移除本会话草稿；丢弃修改等待此前写入完成再清理，防止旧草稿重新出现。启动展示所有可解析和损坏的记录，支持导出、恢复副本及二次确认移除。恢复副本不删除来源恢复记录，也不覆盖原卡。

自动恢复只保证已完成写入的草稿；浏览器强制终止可能中断最后一次异步写入。保留离页提醒及手动保存／导出。作者存档不设固定 5 MB 上限，实际可用容量受浏览器配额和设备空间限制。清空站点数据会同时移除存档和模板缓存，外部 JSON 备份仍需保留。

## 装备版本与附属威能

EquipmentItem 保留旧 level、price、enhance、crit、prop、power 字段，新增可选 versions、selectedVersionId 与 powers。旧装备的神通文本不自动重写；读档补齐空数组。版本带稳定 ID、非负整数等级与文本价格／淬炼／暴击，可由作者自行增删。应用版本更新当前四个字段，特性与附属威能不变；复制资源刷新版本和威能 ID，同时映射选中版本。

模板只读取明确的等级列表与数值表：没有宏定义的价格和增强加值保持待填写，不按等级默认推算。增强作用对象、暴击、特性及行内威能分开读取；无法拆分的规则保留全文与警告，原版 JSON 快照保留全部数据。装备附属威能复用 MoveItem 和 PowerEditor／PowerCard，与装备一起保存、搜索和分享，也可独立导出为招式。未注明威能等级时记录为 0 并提示核对。

装备等级宏仅按已核验的 4E NEXT Procedure 数值单元格精确匹配（203 个定义），不按后缀猜测。普通、消耗品、无增强与单等级宏各自保留原定义；显式表格优先，声明等级限制宏填充范围，冲突给出转换提示。未知宏保留在正文与原始快照中。此数值表不包含原版条目正文，更新时须核对上游 Procedure。
