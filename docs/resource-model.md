# 资源数据模型

## 身份与类目

`src/types.ts` 的 `ResourceMap` 将九个类目映射到各自资源类型，`DB` 按此映射保存数组。`id` 使用 UUID；条目名称允许暂时为空。已存在的旧 ID 保留，重复导入通过跳过、覆盖或分配新 ID 的副本处理。

根骨／出身／先天命格是种族信息的拆分。修行传承与成道之途是独立资源组合，特性和威能带稳定 ID，附属威能随资源导出。复制资源时递归更新所有内嵌 ID。

## 威能与复杂规则

`MoveItem.type` 的 basic/special/ultimate 分别表示随意／遭遇／每日，不限制外家、内家等风味。动作使用 `ActionMap` 的键，防御使用 AC/Reflex/Fortitude/Will；迁移中文旧值。旧 `react` 保留为“变招（旧版）”，不推测作者指即时打断还是即时反应。

`level` 是威能等级；`acquiredLevel` 是组合资源中的获得等级，两者独立。`rules` 是可排列的标题／全文段落，承载次攻击、强化、后续效果、次威能等复杂结构。`source` 是出处，`sourceText` 保留完整参考原文，不印在卡片上。未知扩展字段保留。

## 版本与恢复

备份格式：`{ schemaVersion: 1, exportedAt, data: { moves: [...], ... } }`。支持全库、单类目与单条资源备份，仍可导入旧版直接按类目排列的 JSON。缺少类目视为空库；支持的资源字段类型错误或未来版本导致整次导入失败，不部分写入。

新存档使用单键 `wuxia_resources_v1`，整库一次写入，避免部分库保存成功。若没有新键，读取 `Config` 中的旧键，迁移字符串等级、中文动作／防御、缺少的数组及特性 ID。旧键原文不改写。

加载异常保留原始字符串与错误，暂停自动保存。作者先下载恢复原文，再明确选择用当前数据继续。写入失败保留内存中的编辑稿，提示未保存、支持重试和 JSON 备份，并在离开页面时提醒。恢复文件属于原始故障快照，不是可直接导入的资源备份。

4E 原版资料使用独立的 IndexedDB 缓存层，资料包支持远程获取或本地导入；仅选中并复制的草稿进入作者存档。缓存的原子更新、容量显示、来源快照与转换边界见 [只读模板库](templates.md)。

外层增加可选 `terminology` 字段，与资源同键保存。旧版本 1 存档缺少此字段时加载默认术语；词库故障保留原始存档并暂停覆盖。动作、防御、频率名称快照存入资源文本扩展字段，详细行为见 [分类术语库](terminology.md)。
