# 卡片编辑、保存与分享

## 编辑与保存

编辑器修改先进入页面草稿，不立即覆盖原卡。工具页提供“覆盖保存”（保留原 ID）、“复制保存”（创建新 ID 并添加副本名）、“不覆盖另存”（指定新名称与新 ID）和“放弃修改”。复制会重新生成内嵌特性、规则段和威能 ID，保留原版对照快照。离开有修改的卡片时提供保存／复制／放弃／继续编辑；刷新或关闭页面有离页提示。页面草稿未持久化，确认离页丢弃后不会恢复。

提交保存仍走原有 localStorage 存档、术语、恢复与失败提示流程。提交后若显示“有未保存修改”，应重试或导出备份。全库备份和当前卡导出包含当前编辑稿，可在存储不足时保留成果。术语自动收录独立保存，不提交卡片草稿。

## 单卡与多选

预览提供单卡 JSON 和可编辑 PNG。修行传承／成道之途可以选择完整卡、概要卡或单张附属威能；附属威能的独立导出携带 moves 条目，概要卡携带整个父资源数据，图片内容与恢复范围因此不同。

工具页列表保留手动多选、选择搜索结果、合并 JSON，新增单卡 JSON ZIP 与 PNG＋JSON ZIP。顶栏“卡牌库”支持跨九类资源检索、多选与打包。一次 ZIP 最多 200 张卡，文件总量不超过 100 MB；图片顺序生成，失败不下载不完整包。每张卡的文件名包含序号，避免重名覆盖。

PNG 使用标准未压缩 UTF-8 iTXt 文本块，关键词为 WuxiaResource，携带原有版本 1 资源备份。写入与导入验证 PNG 长度、CRC、结构，元数据上限 20 MB。图片可正常浏览，无需联网；数据包括不显示在卡面上的来源和原版对照。截图、转码、社交平台压缩或剪贴板处理可能删除元数据，普通图片不执行 OCR，也不宣称完整还原。

## 导入

顶栏“导入全库／卡片”接受版本化或旧版 JSON、可编辑 PNG、卡片 ZIP。工具页“导入卡片”使用同一校验流程。导入先预览再选择：保留本地／覆盖重复 ID／全部生成独立副本。全部校验成功后才执行，失败不改作者数据。

ZIP 支持每张卡的 PNG 和 JSON；数据一致的同类同 ID 条目合并一次，数据不同则拒绝整包，避免歧义。只读取 JSON／PNG，不写入磁盘路径。解压总量限制 100 MB、500 个文件，拒绝超限；携带术语的整库 JSON 请单独导入，不混入卡片包。导入前须先处理当前未保存稿。

工具页“导入 4E 模板”直接读取已下载的只读资料缓存，可切换资料包、搜索并查看原版正文，只显示当前工具适用的类别。选择后导入独立可编辑资源，保留来源、原始字段和转换提示；种族按当前根骨／出身／先天命格工具拆分，附属威能从同一缓存资料包解析。未下载时提供资源管理入口，不自动联网。未保存的编辑稿须先处理，已有资源和只读缓存不会被覆盖。4E JSON 文件仍可通过“导入卡片”导入。

## 验证边界

自动验证中文及未知字段 PNG 往返、重复元数据替换、CRC 损坏拒绝、PNG／JSON ZIP 去重、导入大小和重复 ID、原版引用转换、保存原卡不变及导航保护。实际截图尺寸、PNG 像素效果、作者信息在不同屏幕的单页布局及浏览器下载交互仍按用户要求交由部署后人工审核。
