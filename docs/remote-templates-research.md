# 4E NEXT 远程模板适配调查

调查日期：2026-10-03。此文记录源码与只读 HTTP 探测结果。远程下载与 IndexedDB 资料包管理已按此调查接入，实际功能及边界见 [只读模板库](templates.md)。

## 可用数据

源码 `web/src/data/loaders.ts` 从 `data/` 读取 JSON；`web/scripts/copy-data.mjs` 将派生分类、索引、关系文件复制到公开目录。实测 https://4e-next.banque.ltd/data/manifest.json 返回 HTTP 200、application/json、Access-Control-Allow-Origin: *，schemaVersion 为 1，generatedAt 为 2026-08-19T07:37:39.414Z，全站 total 为 16031。

七类合计 15531 条、32847705 字节（约 31.3 MiB），均返回 HTTP 200 与通配跨域响应头，各类条数符合清单。全站其他类别暂不属于现有九类资源映射范围。

`data/search-index.json` 为 5721740 字节，可用于名称、类别、来源检索；`data/relations.json` 为 375959 字节，包含 powerByGrantedBy。名称索引并不替代正文，附属引用仍以正文 wiki.transclusions 为准。

## 转换验证

读取线上七类派生 JSON，以现有转换器遍历可用目标类目，生成 15773 条草稿，无结构转换异常；验证原始快照保存和种族引用威能。一个种族可进入三个目标类目，且多个种族威能会形成多个命格，草稿数因此大于源条目数。

出现 4818 条核对提示，属于频率、等级、复杂动作、未解析引用或规则拆分等提示，不能把零结构异常解释为完整语义准确。职业特性和装备多等级仍按现有边界保留正文。线上数据包含 sourceText、fields、wiki 和分类专用字段，可复用现有适配器；没有 canonical provenance 内容哈希，需另计算下载快照哈希，不冒充上游提供的哈希。

## 建议实现

1. 用户主动选择“从 4E NEXT 获取”，使用固定 HTTPS 地址、GET、credentials: omit，不发送用户资源，不使用代理复制正文。
2. 先读取并验证清单与搜索索引。仅允许七个已知分类及固定文件路径，限定版本、体积、条数、字段类型和重复 ID。提供进度、取消、失败重试。
3. 按分类下载正文；源站将 8903 条威能放在单个文件中，不能声称支持单条远程下载。涉及附属威能时需加载威能分类，可提供可选“下载全部供离线使用”。
4. IndexedDB 独立数据库保存源索引、分类与下载元数据，不改变现有作者 localStorage。保存 URL、实际下载时间、清单时间、schemaVersion 和浏览器计算的 SHA-256。事务成功后切换有效快照；下载或存储失败保留旧版本。
5. 页面重开使用已下载资料；提供刷新资料、清除缓存、来源链接、离线可用状态。首次未下载的分类不能离线使用。浏览器清理站点数据仍会删除缓存，作者备份保持独立。
6. 数据更新提示以实际文件哈希为准。源站虽提供 ETag，却未暴露 Access-Control-Expose-Headers，浏览器脚本无法直接读取 ETag；不能依赖手动条件请求。generatedAt 不等于每个分类最新版本，也没有原子数据集承诺，更新时需核对索引、正文 ID 和引用，并保留不一致提示。

## 边界

HTTP 探测携带吾侠站点 Origin，确认服务器响应允许跨域；未按用户偏好打开页面进行浏览器实测，因此实际页面下载、IndexedDB 配额、网络中断与移动端仍需后续验证。公开可读和允许第三方长期缓存的授权不是同一事项；此调查确认技术可行性，未找到新增内容再发布许可。研究快照与临时脚本只保存在 Git 忽略的 .local-templates，不上传仓库或部署。
