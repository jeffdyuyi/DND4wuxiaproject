# 4E 只读模板库

工具栏“资源管理”提供浏览器缓存占用、资料包管理和当前包检索。顶部显示浏览器报告的同源占用／配额、资料包 JSON 大小、作者数据 JSON 估算和最大资料包；未知配额不会假定为 5 MB。左侧可获取或更新 4E NEXT 初始资料、导入、切换、导出与删除缓存；右侧支持类别筛选、中英文名称／关键词／等级／出处／正文搜索、分页及原始字段查看。选定模板后选择目标类目，点击“复制为…草稿”。新草稿使用独立 UUID，不覆盖作者已有资源，也不修改只读原版。

## 数据范围

来源为本地 4E-NEXT-main 的 canonical v1 数据快照（生成时间 2026-08-21）。七类共 15,531 条：威能 8,903，职业 77，种族 54，专长 3,202，装备 2,603，典范之道 577，传奇命运 115。此数量表示当前快照内容，不代表全部出版物或译文完整。

首次点击“获取 4E NEXT 初始资料”，浏览器直接从 https://4e-next.banque.ltd/data/ 获取清单和七类正文，不携带凭据或上传用户资源。显示分类进度，可取消下载。清单版本、路径、数量与正文经过校验，下载前后清单变化则拒绝保存；原站不提供原子快照承诺，此检查不保证发现所有上游变化。只有完整资料验证成功才在 IndexedDB 事务中更新缓存，失败保留旧版。无需每次手动获取；再次打开恢复上次使用的资料包。缓存可供已打开的页面在断网后检索，不承诺应用网页本身能在首次离线时启动。

也可运行 `node scripts/extract-templates.cjs <4E-NEXT-main项目路径>` 生成 `.local-templates/4e-next-pack.json` 并导入。此目录被 Git 忽略，完整正文不会随构建部署。公开版本仅包含空索引；不能将工具的 MPL 2.0 许可当作规则正文的授权。

单个导入包与一次远程下载上限为 100 MB、100,000 条。验证版本、类别、字段、引用和重复 ID，缓存读写与元数据使用同一事务。IndexedDB 数据库 `wuxia_template_cache_v1` 的 packs／info／settings 分别存储正文、来源版本／下载时间／JSON 字节大小／SHA-256 与当前包。SHA-256 为本地计算，不冒充原站 canonical provenance。容量由浏览器和磁盘决定，不沿用 localStorage 约 5 MB 的限制；可申请 persistent 保留，拒绝时仍使用普通缓存。浏览器清理、隐私模式或空间回收可能移除缓存，可导出资料包备份。

作者资源、术语和旧存档仍使用原有保存流程，未迁移到 IndexedDB；大资料包缓存不占其 localStorage 配额，但作者存档自身仍可能达到原有上限。删除资料包要求窗口内确认，不删除已复制的草稿。清除当前包后自动选择剩余包，没有剩余包则清空只读索引。

## 映射与转换边界

- 威能 → 武学招式：频率、动作、等级、关键词、范围、规则表格。首个命中／效果等字段进入主字段，重复和未知段落进入附加规则。复合表格另保留完整正文；无法识别的攻击防御和动作标明核对，不猜测。
- 职业 → 武林门派：概要、生命、回复力、熟练项与技能；职业特性／变体目前保留在完整说明，尚未自动整理为各项门派特技。
- 种族 → 根骨／江湖出身／先天命格：按选择分别复制体征属性、语言技能、引用的种族威能。可分别复制三个方向，不强制作者的能力分配。多项种族威能会生成多个命格草稿；没有可解析威能时保留全文供人工选择。
- 专长 → 武道造诣：层级、前提和增益正文。
- 装备 → 神兵宝甲：类型、部位、最低原版等级和规则全文；多等级、价格、增强、重击和物品威能尚需作者按选用版本拆分。
- 典范之道／传奇命运 → 修行传承／成道之途：前提、等级特性、不朽说明与引用的附属威能。获得等级与威能等级分别保留。缺失引用保留名称与提示，不虚构补齐。

`templateReference` 保存原版条目 ID、类别、数据版本、内容哈希和原始 JSON 字符串；`templateWarnings` 保存需核对项。先天命格额外保存种族父条目 ID。使用原始 JSON 字符串防止复制资源时递归刷新原版条目 ID。

编辑器“4E 原版对照”显示保留的原版正文、字段及转换提示；编辑草稿不会改写此参考快照。原始 HTML／Wiki 作为文本或 JSON 展示，不执行脚本、宏或图片。规则无法可靠转换时保留正文；不将仅改名视作规则等价。

## 验证

自动测试遍历当前快照全部条目的可用目标类目，检查转换结构、来源保留、引用解析与缺失处理；另验证复杂威能段落、等级章节、不朽说明、独立备份和加载错误。UI 与实际图片导出按用户要求保留给部署后的人工审核。
