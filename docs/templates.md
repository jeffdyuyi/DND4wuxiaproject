# 4E 只读模板库

工具栏“4E 模板”提供类别筛选、中英文名称／关键词／等级／出处搜索、分页、正文与原始字段查看。选定模板后选择目标类目，点击“复制为…草稿”。新草稿使用独立 UUID，不覆盖作者已有资源，也不修改只读原版。

## 数据范围

来源为本地 4E-NEXT-main 的 canonical v1 数据快照（生成时间 2026-08-21）。七类共 15,531 条：威能 8,903，职业 77，种族 54，专长 3,202，装备 2,603，典范之道 577，传奇命运 115。此数量表示当前快照内容，不代表全部出版物或译文完整。

运行 `node scripts/extract-templates.cjs <4E-NEXT-main项目路径>` 从 canonical JSONL 生成 `.local-templates/4e-next-pack.json`。在部署页面打开“4E 模板”，选择该资料包，即可检索、对照和复制。此目录被 Git 忽略，完整正文不会随构建部署。公开版本仅包含空索引；资料包的再发布授权尚未确认，不能将工具的 MPL 2.0 许可当作规则正文的授权。

导入资料包限制为 100 MB、100,000 条，验证版本、类别、字段、引用和重复 ID 后才替换当前资料。验证失败保留已有资料。资料仅驻留当前页面内存，不上传服务器、不进入 localStorage 或作者全库备份；刷新需重新导入。复制的草稿通过既有保存与备份功能持久化。仍保留分块加载接口供未来获得授权的数据源使用，取消与快速切换会中止旧请求。

## 映射与转换边界

- 威能 → 武学招式：频率、动作、等级、关键词、范围、规则表格。首个命中／效果等字段进入主字段，重复和未知段落进入附加规则。复合表格另保留完整正文；无法识别的攻击防御和动作标明核对，不猜测。
- 职业 → 武林门派：概要、生命、回复力、熟练项与技能；职业特性／变体目前保留在完整说明，尚未自动整理为各项门派特技。
- 种族 → 根骨／江湖出身／先天命格：按选择分别复制体征属性、语言技能、引用的种族威能。可分别复制三个方向，不强制作者的能力分配。多项种族威能会生成多个命格草稿；没有可解析威能时保留全文供人工选择。
- 专长 → 武道造诣：层级、前提和增益正文。
- 装备 → 神兵宝甲：类型、部位、最低原版等级和规则全文；多等级、价格、增强、重击和物品威能尚需作者按选用版本拆分。
- 典范之道／传奇命运 → 修行传承／成道之途：前提、等级特性、不朽说明与引用的附属威能。获得等级与威能等级分别保留。缺失引用保留名称与提示，不虚构补齐。

`templateReference` 保存原版条目 ID、类别、数据版本、内容哈希和原始 JSON 字符串；`templateWarnings` 保存需核对项。先天命格额外保存种族父条目 ID。使用原始 JSON 字符串防止复制资源时递归刷新原版条目 ID。

编辑器“4E 原版对照”显示保留的原版正文、字段及转换提示；编辑草稿不会改写此参考快照。原始 HTML／Wiki 作为文本或 JSON 展示，不执行脚本、宏或图片。规则无法可靠转换时保留正文；不将仅改名视作规则等价。
