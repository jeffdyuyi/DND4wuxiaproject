# 关键词与术语置换

工具统一管理原版名称、置换名称、历史别名、分类、释义和来源。原版词来自 `src/data/4e-terms.json`、本地 `4e wiki.html` 的术语表和工具标准字段；提取的术语与释义保存在 `src/data/4e-glossary.json`。生物关键字单独归入扩展分类。

置换栏为空时使用原版名称，填写后界面、选词、规则正文和已有卡片统一呈现置换名。设置随术语库存入资源档案。隐藏只限制候选词，不关闭已存在的置换。自定义词也可改名及恢复原名。原版名称与稳定 value 不随改名变化；动作、防御、频率按稳定标识呈现当前名称，旧快照保留在数据中用于兼容。

React 文本显示通过 TermDisplay 读取当前对应表，不直接修改 DOM 或资源数据。规则 Markdown 在文本 token 层显示置换，链接地址、代码、原版参考全文和来源保持原文。正文按已登记术语最长匹配，单次替换，不重新处理结果；无法确定对应关系的跨分类同名历史别名保持原文，不猜测含义。新增输入和选词尽量保存原版名称；无法唯一逆向解析的名称保留作者输入。普通自由文本中的同名词按登记术语处理，作者需避免把规则术语设置成过于宽泛的普通词。

明确把原有武侠候选词用作一个原版词的置换时，将该候选合并为原版词的别名。清空后，同一别名在旧卡片中恢复为原版名称。更名历史保留供旧卡片显示解析。

术语库支持分类、搜索、置换状态筛选、释义查看、新增、隐藏、清空、JSON 导出和合并导入。合并导入会更新文件中相同标识的设置，保留文件未包含的本地词；先完整校验再写入。旧版词库升级保留名称、隐藏状态及自定义词，并补充新分类；损坏数据继续沿用原有恢复机制。

全库备份、单卡 JSON、PNG 内嵌存档和批量包携带术语设置。PNG 及批量导出渲染使用当前词库；导入资源时遵循现有本地设置优先的合并策略，单独合并导入术语库可明确更新配置。此功能仅改变呈现名称，不承诺武侠置换与原版规则等价。

## 已确认的武侠默认对应

反射→身法；移动动作→移动。即时打断、即时反应、借机动作和无动作保留原称呼。旧动作标识 mov 及其“身法”快照按动作身份显示“移动”；泛用“身法”别名归属反射，不逆向识别为移动动作。

presetRevision=1 标记此次默认对应升级。无标记旧库中尚未置换、且没有更名历史的标准词补入预设；保留自定义改名、隐藏设置与可辨识的清空记录。已关联的同名武侠候选合并为原版词别名；已知对应的武侠候选被作者改过名字时，将该名称和隐藏设置带入标准词，保留更名历史。后续清空置换不重新填回默认值。

同名术语按字段分类显示：效果“区域”显示“阵法”，攻击范围“区域”仍显示“区域”。关键词行与选词使用关键词分类，范围行及范围构建器使用范围分类；正文默认显示明确设置的置换，不让其他分类未更名的同名参考阻止置换。
