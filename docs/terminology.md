# 分类术语库

工具栏的“术语库”提供分类搜索、新词添加、显示名称编辑、隐藏及恢复、自动收录开关、独立 JSON 导出。自定义词可选填对应的原版参考；此关联只供创作对照，不判断规则等价。

## 候选来源

`src/data/4e-terms.json` 从本地 4E-NEXT-main 的分类配置、武器参考表、状态表和装备部位字段提取 187 个术语。保留各词的来源，不复制完整规则正文。重新提取命令为 `node scripts/extract-terms.cjs <4E-NEXT-main项目路径>`。脚本只解析静态字面量和表格字段，不执行参考项目代码。

现有武侠关键词、动作和防御显示名称保留。力量来源、伤害、效果、器材和其他关键词与具体武器、武器组、法器、护甲、部位、状态分开管理。

## 编辑行为

- 威能关键词按分类点选，支持筛选；自定义关键词仍可自由输入。新词按当前选定分类收录，默认分类为“其他关键词”。
- 已输入完整关键词后按回车或离开输入框才自动收录；逗号、分号、顿号和换行可分隔多个词。关闭自动收录后仍可手动点击“收录新词”。已有词不会被收进错误的其他分类。
- 防御、动作与频率使用单选；防御和动作允许输入自定义完整名称后按回车使用。随意／遭遇／每日的标识固定，显示名称可改。
- 装备类型和部位保留自由输入，并提供候选建议。混合类型字段中新词默认收录为武器组，可在术语库按正确类别手动添加。
- 命中、效果、附加规则等正文可在光标位置插入术语；不从整段正文自动猜测或提取新词。

## 兼容与持久化

词条保存稳定 ID、分类、显示名称、稳定值、来源类型、可选原版参考和隐藏状态。同类名称和稳定值不可重复；隐藏不删除原版参考。普通关键词及装备仍写入原有文本字段，不批量替换旧资源。

威能选择动作／防御／频率时保存 `actionLabel`、`defLabel`、`typeLabel` 显示快照。旧资源无快照时沿用原显示规则，词库改名不会改变旧卡片。编辑时可选择新的名称并更新该条卡片的快照。

存档和全库备份在版本 1 外层增加可选 `terminology`，与资源一次性写入同一个存储键。旧备份仍可读；独立词库备份使用 `data: {}`。单条资源备份通过文本和快照保持独立，不必附带整套词库。

导入先校验整份资源与词库。术语仅增补本地未有的词，已有标识／名称以及自动收录设置保留，不按资源的“覆盖／复制”选项改写词库。损坏词库暂停存储覆盖并保留原始恢复数据；可读取的资源仍保留。
