# 卡片与编辑格式

## 招式 / 附属威能

统一使用 PowerEditor 和 PowerCard。顺序为：标题与频率／等级、意境、关键词、动作／范围、触发、目标、攻击、命中、失手、效果、维持、特殊、附加规则段、来源。动作与频率不强制功法性质。

空规则字段省略；原版全文仅供编辑与对照。附加规则段可增删与排列。Markdown 支持文本强调和安全链接，换行保留；作者输入的 HTML 和图片作为无执行能力的文字处理。

## 修行传承与成道之途

顺序为：名称／起始等级、引言、前提、资源说明、分级特性、附属威能、成道终局（可选）、来源。默认特性与威能节点参考原版但不锁定数量或等级。空白特性及威能不显示。

概要卡保留特性和附属威能清单；完整卡包含威能全文；每项附属威能还可独立预览和导出。威能等级和获得等级不同则均显示。此格式不规定作者作品的境界、世界或故事结局。

## 验收

确认旧数据可显示、切换条目不串状态、特性改名不失焦、范围连续编辑不重置。用长段落、中文换行、多规则段与多个附属威能检查预览及 PNG；预览缩放不降低导出分辨率。复制图片需要浏览器支持安全上下文中的剪贴板，失败时保留 PNG 下载途径。

不要在资源卡中印入保存状态、实现说明或编辑器按钮。小屏优先让作者能完成列表、编辑和预览流程，不强行维持三栏布局。

## 神兵宝甲

当前等级、部位、价值、淬炼及暴击为基础字段。等级版本表保留作者的各版本数据，应用版本后可预览和导出该版本当前卡；不自动缩放特性或重算威能。完整卡包含特性、旧神通正文与附属威能全文；概要卡列出威能名称；单独威能卡独立导出为 moves，父装备及全部版本仍可通过完整／概要 JSON 恢复。空字段不显示，复杂威能的附加规则不省略。
