# 4E 资源转换

按用户要求转换资源，避免把模板接入扩展成完整世界设计或车卡规则引擎。先读取项目根目录的 AGENTS.md；数据变更查阅 [资源模型](../../../docs/resource-model.md)，卡片变更查阅 [卡片格式](../../../docs/card-format.md)。

本地 4E 数据按类别读取相关条目，同时检查 flavorText、details、sourceText、fields 与嵌入引用。仅名称或风味不足以确定完整规则。种族信息需按根骨／出身／先天命格拆分，典范之道进入修行传承，传奇命运进入成道之途。

区分仅改风味和实际规则改动。保留来源条目 ID、出处、数据版本和原文；无法可靠拆分的次攻击、强化或后续效果放入附加规则段或 sourceText，并说明尚未转换的部分。遇到缺失引用，保留名称和原文标记，不能自行虚构补齐。

转换成果必须覆盖编辑、预览、保存、搜索和独立导出；附属威能内嵌分享，原版资料保持独立只读。验证版本迁移、复杂规则保留和 JSON 往返。发布与提交遵循用户的实际授权，不因使用本技能自动执行。
